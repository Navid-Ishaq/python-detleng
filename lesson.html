1 · Understand

Python is a programming language designed to let you express instructions in readable code. Your first instruction will use print(), a built-in Python function that displays something as output.

Core idea: code is an instruction. You write the instruction, Python runs it, and you observe the result.

What happens line by line?

1print("Hello, Python!") asks Python to display the text between the quotation marks.
2The text inside quotation marks is a string. Strings are how Python represents text.
3When you press Run Python, the output appears in the panel on the right.
This page loads Python in the browser using Pyodide. The first run may take a few seconds because the Python runtime has to load.
